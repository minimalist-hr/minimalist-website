# SEO and metadata

## Per page

Rendered by `src/components/SeoHead.astro` from the props of `BaseLayout`.

| Tag                                                               | Source                                                                                   |
| :---------------------------------------------------------------- | :--------------------------------------------------------------------------------------- |
| `<title>`                                                         | The view's `title` (e.g. "Work — Minimalist")                                            |
| `<meta name="description">`                                       | The page lede; case study `summary`; insight `excerpt`; falls back to `site.description` |
| `<link rel="canonical">`                                          | `alternates[locale]` as an absolute URL on `https://minimalist.hr`                       |
| `<link rel="alternate" hreflang>`                                 | One per language, plus `x-default` → English                                             |
| `og:type`, `og:site_name`, `og:title`, `og:description`, `og:url` | Same values as above                                                                     |
| `og:locale`, `og:locale:alternate`                                | `en_GB` / `hr_HR`                                                                        |
| `og:image` (+ width, height, alt)                                 | `/og/default.png` (1200×630, integrated mark on ink); a page may pass its own `image`    |
| `twitter:card`                                                    | `summary_large_image`                                                                    |
| `<html lang>`                                                     | `en` or `hr`                                                                             |
| `<meta name="robots" content="noindex">`                          | Only when `noindex` is passed (the 404 pages)                                            |

Rules: one `h1` per page, headings in order, unique title and description per page and
language, written in the brand voice.

## Structured data (JSON-LD)

Built in `src/lib/structured-data.ts`, rendered by `JsonLd.astro`.

| Page       | Types                                                                                     |
| :--------- | :---------------------------------------------------------------------------------------- |
| Home       | `Organization` (name, legal name, URL, logo, email, postal address)                       |
| Case study | `BreadcrumbList` (Minimalist › Work › case study)                                         |
| Insight    | `Article` (headline, description, date, language, author, publisher) and `BreadcrumbList` |

## Sitemap

`/sitemap.xml` is generated at build time by `src/lib/sitemap.ts`, not `@astrojs/sitemap`
(which pairs languages by matching paths and can't handle translated slugs).

- Every static route from the route map (Insights only if `showInsights`).
- Every **published** case study and every non-draft insight, paired by `translationKey`.
- One `<url>` per language version, each listing all versions and `x-default`, in Google's format.
- The 404 pages are not included.

## robots.txt

Generated by `src/pages/robots.txt.ts`:

```text
User-agent: *
Allow: /
Disallow: /api/

Sitemap: https://minimalist.hr/sitemap.xml
```

## Keeping previews out of search

- The staging deploy appends `X-Robots-Tag: noindex` to `dist/_headers`.
- Production gets the same unless `ALLOW_INDEXING=true` (set since launch).
- Production answers only on `minimalist.hr` (`workers_dev: false`) and `www` redirects to the
  apex, so there are no duplicate hosts.

## Search consoles

The sitemap is submitted to Google Search Console and Bing Webmaster Tools. After adding pages
there is nothing to do; the sitemap updates with the build.

## Checklist for a new page

- Unique `title` and description in both languages.
- `alternates` passed to `BaseLayout` (or `noindex` if it shouldn't be indexed).
- A route map entry, so it reaches the sitemap and the language switch.
- Structured data if a schema.org type fits.
